# grundlagen_informatik_1-uebung_3

tasks for learning the language ""Phyton" 

Aufgabe1

Entwerfen Sie je eine Funktion, die den Radius eines Kreises als Parameter erhält und

a) dessen Umfang U = 2 π r

b) dessen  Flächeninhalt A = π r²

berechnet und zurück gibt.

Aufgabe2

Entwerfen Sie je eine Funktion, die

a) die zurückgelegte Strecke s = 1/2 g t²

b) die Geschwindigkeit v = g t

nach einer bestimmten Zeit im freien Fall berechnet und zurück gibt.
Die Zeitdauer ist der Funktion als Parameter zu übergeben.
Das Ergebnis der Funktion b) soll in m/s und im km/h ausgegeben werden.

Aufgabe3

a) Entwerfen Sie eine Funktion, die zwei Zahlen a und b übergeben bekommt und 
ausgibt gibt, ob a ein Teiler von b ist.

b) Entwerfen Sie eine Funktion, die eine Zahl übergeben bekommt und die letzten 
beiden Ziffern der Zahl zurück gibt, wenn die Zahl größer oder gleich 100 ist. 
Bei zweistelligen Zahlen, ist nur die letzte Ziffern zurückzugeben, ansonsten der 
Wert 0.

Aufgabe4

Entwerfen Sie eine Funktion, die ein Datum als ganze Zahl (acht-stellig in der Form 
TTMMJJJJ)¹ als Parameter erhält. Das Datum soll in der Form TT.MM.JJJJ 
zurückgegeben werden.
¹ oder sieben-stellig TMMJJJJ bei einstelligen Werten für den Tag (z. B. 05.01.2026)

Aufgabe5

Entwerfen Sie eine Funktion, die dem Nutzer im Krankheitsfall „gute Besserung“ 
wünscht. Der Gesundheitszustand (gesund/nicht gesund) wird der Funktion als 
Parameter übergeben.

Aufgabe6

Ein Unternehmen zahlt Boni für eine lange Betriebszugehörigkeit.
Legen Sie je eine Variable für das Grundgehalt sowie die Dauer der Betriebszugehörigkeit an 
und berechnen Sie die Auszahlung in einer Funktion (Übergabe der Daten in Parametern).
Mitarbeitende bekommen ab dem 5. (bzw. 10., 15.) Jahr einen Bonus von 3% (8%, 18%). 
Die Ausgabe des Auszahlung erfolgt im Hauptteil.
Entwerfen Sie mind. 3 verschiedene Algorithmen!
